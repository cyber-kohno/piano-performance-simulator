### 目的とユーザーとの合意

- `apps/3d-motion-lab` は、演奏動作の方式・見た目・対応範囲を見極める検証アプリ。方向性が固まったら別プロジェクトで再設計し、長期保守用のコード・テストを整える方針。
- 検証アプリは Vite + Svelte + TypeScript + Three.js。Tauri、楽譜エディタ、自動運指、音声は今は追加しない。入力は静的JSON。
- **検証時点から88鍵すべてを主カメラ内に収める。** 手元の拡大表示は補助表示。全鍵表示を省略する代替にはしない。
- 一度に最終目標まで実装せず、映像をユーザーと確認しながら段階的に進める。最終目標は実写に近い演奏映像だが、現在は簡易形状・動作の対応確認が中心。

### 重要な制約・設計境界

- 3音以上、黒鍵を含む和音、同じ手の開始時刻／離鍵時刻が異なる重複音、レガート、自然な指くぐり・指またぎは未対応。音階の親指への持ち替えは手全体の移動で近似する。
- 同じ指への2音指定、同じ手の和音での重複鍵盤、交差する運指、簡易モデルで届かない2音、左右の同一鍵への同時接触は検出して拒否。人体の演奏可能性を判定する仕組みではない。
- 接近／離鍵の基準時間は各120ms、移動の基準時間は300ms。音間が540msより短ければ離鍵・移動・接近を12:30:12で短縮。**現在の最小音間は10msであり、540msは下限ではない。** 押下は60msで底に到達し、`duration`が60ms未満なら到達前に離鍵する。
- 動作は時刻から評価し、フレームの積み重ねで位置を決めない。入力検証・和音計画・描画を分ける。
- 単音では指先の弧に伴うX/Zずれを手の位置で補正する。和音では共通の掌位置を固定し、各指の角度を求める。白鍵の接触奥行きはZ=0.008〜0.05mで指別に選ぶ。
- 手首の傾きは空中移動中のみ。保持中の接触点を壊す一律の平滑化は避ける。前腕は長さ245mmの追従表示で、肩・上腕・解剖学的に自然な肘は扱っていない。
- 物理演算・衝突回避・人体速度制限・音声・ペダル・動画出力は未実装。他指や手同士の干渉を許容した検証段階。全面的な人体IKはなく、指の2節モデルに対する幾何計算を用いる。

### 別環境での再開手順

**このMarkdownだけではアプリは再現できない。** 少なくとも `apps/3d-motion-lab` のソース・設定・`package.json`・`package-lock.json`、および `docs/plan` を同じ相対配置で移す。`node_modules` と `dist` は再生成でき、別OSのものを持ち込む必要はない。Gitのコミットやリモートへの反映は本作業で実施していないため、別環境に最新ファイルが届いていることを確認する。

1. この「現在の状態」を読む。
2. [アプリREADME](../../apps/3d-motion-lab/README.md)で詳細な仕様と目視確認手順を読む。[初期構想](piano-performance-simulator-spec.md)は背景資料として読む。初期MVPの限定範囲を、実装済みの機能へ適用し直さない。
3. Node.js 24系とnpmを用意する。直近の実行環境はWindows、Node.js 24.13.1。OS別のネイティブ機能や外部3Dモデルは不要だが、他OSの動作は未確認。
4. プロジェクトルートから次を実行する。インストールにはnpmレジストリへの接続が必要。

   ```sh
   cd apps/3d-motion-lab
   npm ci
   npm run check
   npm test
   npm run build
   npm run dev
   ```

5. ターミナルに表示されたURLをWebGLが使えるブラウザで開く。通常は`http://127.0.0.1:5173/`。このチャットで使っていた5174に揃えるなら`npm run dev -- --port 5174 --strictPort`を使う。**別環境では開発サーバーの起動が必要で、以前のlocalhost URLだけでは再開できない。**
6. 07／08の音階、05の2音和音、06の移動比較、03の両端を確認する。全鍵表示と手元拡大、接触位置、指くぐり近似などの限界も確認してから改修する。

- 次の到達点として、近接移動・跳躍・和音切替の自然さを検証。初期選択に06シナリオを追加。
- 空中の移動だけ5次補間で加減速し、距離に応じて8〜65mm持ち上げる。移動時間は到着前の空き時間と距離から求める。指は移動時間75%までに次の音の準備姿勢へ。
- 手首を軸に空中移動時だけ前後・左右へ傾け、接近前に戻す。接近〜離鍵の動作と押鍵時刻は従来と同じ。全体へ一律に平滑化して接触点を動かす処理は行わない。
- UIに従来／新方式の比較切替を追加。同じ時刻で姿勢を比較し、保持中はどちらも同じ接触位置を保つ。
- 肘〜手首の前腕を表示（表示切替可）。長さ245mmで、肘は身体側の目安へ追従する簡易モデル。肩・上腕・人体可動域・速度上限は未対応。
- 全鍵と前腕が収まるカメラ範囲に変更し、手元拡大は継続。

- 和音間では手の位置と指姿勢を補間。単音・黒鍵単音の既存入力も引き続き対応。
