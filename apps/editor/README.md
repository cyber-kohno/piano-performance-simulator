# Piano Score Editor

2026-10-28時点で、休符込みの記譜列を正本とする新方式の基盤は実装済みです。小節・段ごとに最大3声部を切り替え、配置・削除・和音編集・音価編集・タイ追加・移動・伸縮を検証できます。OSMDによる前後3小節の楽譜プレビューも検証できます。ファイル保存・読み込み、MusicXMLファイル入出力は未実装です。「保存対象」はプロジェクトモデルを指します。

ソロピアノ譜のドメインモデルと、キーボード入力を段階的に検証するアプリです。
Svelte 5 + TypeScript + Viteで構成します。正式なUI表記は英語で統一します。

[設計方針と未決事項](../../docs/plan/score-domain-model/score-domain-model.md)に、Scorehackを基準にした合意を記録しています。

## 起動・確認

Node.js 24系とpnpmを使い、このディレクトリで実行します。

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm check
pnpm build
```

## 保存対象の最小モデル

プロジェクトは初期値・セクション・小節を順序付きの`outline`に並列で持ちます。
小節は直前のセクションに属しますが、セクションの子配列には入れません。
初期値は調号なし（長短調を持たない`fifths`）、4/4、四分音符＝100です。
最初のセクション名は`section0`です。

各小節は実際の長さ、上段・下段を持ち、各段に複数声部を保持できます。
各声部の`elements`は、音符・休符・全小節休符の順序付き配列です。
全小節休符は小節の実長を満たし、通常の全休符とは区別します。
新規小節は上下段のvoice 0を全小節休符で初期化します。

音符・通常休符は`value: { type, dots }`で記譜上の音価を保存します。
開始位置・数値の長さ・終了位置は保存せず、声部内の先行要素と音符種類・付点から導出します。
各声部の合計時間は小節の実長に一致します。
ノートはピッチ配列を持ち、降順・同音重複なしを維持します。指番号はピッチごとの属性です。

上下段と、現在小節・段の最大3声部を切り替えて編集します。カーソル単位は16分・8分・4分音符から選び、移動と新規配置に使います。
単位を切り替えても開始位置や既存ノートの音価は変更しません。
配置は範囲内の休符を消費・分割し、削除は同じ音価の休符へ戻します。
編集範囲外の休符の形と、他ノートの開始位置を維持します。休符自体はピアノロールに描画しません。

別段・別声部のノートとは、時間帯が重なり、和音内のピッチが一音でも一致する場合に衝突とします。
同じ段の別声部も、段と声部IDを使って区別し、同じ規則で走査します。編集対象は現在のアクティブ声部です。
配置・移動・音価変更・伸縮・隣接生成・ピッチ変更・E＋A・範囲編集の確定前に共通の判定を行い、衝突時は操作全体を拒否します。
タイ列は変更対象の全区間、和音は全ピッチを判定します。ピッチ変更時は別声部の同音を自動で飛び越えません。
異なるピッチの同時発音と、一方の終了と他方の開始が一致するだけの場合は許可します。移動は到着位置で判定します。
入力カーソルもこの規則で配置不可を赤く表示します。無関係な既存ノートの衝突は、別のノートの編集を妨げません。

## キー操作

| モード | キー | 操作 |
|---|---|---|
| 共通 | R | Outline / Timelineを切り替え |
| Timeline | Shift＋R | 編集段を上段／下段へ切り替え |
| Timeline | Q | 現在小節・段の声部を順に切り替え、末尾から第1声部へ循環 |
| Timeline | Shift＋Q | 次の声部がなければ現在小節・段に追加。選択は変えない。最大3声部 |
| Outline | 上下 | 要素間の移動 |
| Outline | 左右 | セクション間の移動 |
| Outline | A | 選択位置の次に小節追加。フォーカスを維持 |
| Outline | S | 選択位置の次にセクション追加。フォーカスを維持 |
| Outline | Delete | 要素削除後、直前へフォーカス。初期値と先頭セクションは保護 |
| Timeline | 1 / 2 / 3 | カーソル単位を16分 / 8分 / 4分へ切り替え |
| Timeline | Fホールド＋1 / 2 / 3 | 選択ノートの音符種類を16分 / 8分 / 4分へ変更 |
| Timeline | Fホールド＋. | 選択ノートの付点を切り替え |
| Timeline | Fホールド＋左右 | タイ列全体を入力単位ずつ伸縮し、その範囲だけ自動で記譜を再構成 |
| Timeline | Fホールド＋A | 同じ和音をカーソル音価で直後に生成し、タイ接続して新ノートへフォーカス |
| Timeline | Dホールド＋A | 同じ和音をカーソル音価で直後に複製し、タイ接続せず新ノートへフォーカス |
| Timeline | Dホールド＋左右 | 選択ノート（タイ列なら全体）を入力単位ずつ移動 |
| Timeline | 左右 | 選択中のカーソル単位ずつ移動。既存ノートとの衝突でフォーカス |
| Timeline | 上下 | カーソル／選択ピッチを半音移動 |
| Timeline | A | カーソル単位の音符を配置してフォーカス。選択中ならその末尾に続けて配置 |
| Timeline | Delete | 選択ノートを同音価の休符へ戻す |
| Timeline | Eホールド＋A | 選択ピッチの半音下にピッチ追加して選択 |
| Timeline | Eホールド＋上下 | 和音内のピッチ選択 |
| Timeline | Eホールド＋Delete | 選択ピッチだけを削除。最後のピッチなら休符へ戻す |
| Timeline | Cホールド＋上下 | 調号の構成音だけを移動先にする |
| Timeline | Eホールド＋左右 | 空白や小節境界を越えて前後のノートへ直接フォーカス |
| Timeline | = | フォーカスノートと直後に隣接する同じ和音のタイ接続／解除 |
| Timeline | Shift＋左右 | カーソル状態ではノートをフォーカスせず移動。ノート選択中は前後へ範囲選択を拡張／縮小 |
| Timeline | Escape | 範囲選択を解除し、現在のフォーカスノートだけを残す |

既存ノートにフォーカスすると最高音を選択します。
Shift＋Rで段を切り替えると、位置と入力単位を維持し、ノート非選択・第1声部に戻します。ノート選択中はその開始位置（範囲選択では操作端のノート）を使います。音程は上段C4／下段C3へ初期化します。
OutlineからTimelineへ入るときも上段へ戻し、選択小節の先頭・ノート非選択・四分音符・C4で初期化します。
段切り替えでは複数選択も解除します。Rのキーリピートによる切り替えは行いません。
Shiftを離しても範囲選択は保持します。複数選択中は列を赤で示し、操作中の端に線を表示します。
通常の左／右キーで、選択範囲の左端／右端の単一ノートへ戻ります。E＋左右でも範囲を解除して移動できます。
複数選択中のD＋左右は、ノート間の間隔・音価・和音・指番号を保って選択ノート全体を移動します。
移動先の衝突・曲外への移動・音符単体の小節またぎは操作全体を拒否します。
単一選択のD＋左右は従来どおりタイ列全体を移動し、複数選択では選択した音符だけを移動します。
選択範囲外とのタイが移動によって連続しなくなった場合、その接続を解除します。
Deleteは選択ノート全体を同音価の休符へ戻し、先頭位置を入力カーソルに戻します。
複数選択中の上下キーは全ノートの全ピッチを一律に半音移動します。CやEのホールド中も半音単位です。
ノート内のピッチ選択は持たず、和音内・ノート間の音程差を保ちます。どれか一音でも88鍵の範囲外になる場合は全体を拒否します。
範囲内のタイは維持し、範囲外とのタイで音高が一致しなくなった接続は解除します。
複数選択中のその他の編集は、通常の左右またはEscapeで単一選択へ戻ってから行います。
左右でフォーカス中ノートの開始／終了位置へ入力カーソルを出します。
既存ピッチを飛び越えて最も近い空き音へ動き、88鍵の端では停止します。
和音の最高音と最低音の差が長10度（16半音）以上になるピッチ移動・E＋Aでの追加は拒否します。
EとCの同時ホールドはEのピッチ選択操作を優先します。
Eはピッチ選択・追加・削除と左右のノート移動に使います。ホールド解除はキー解放・フォーカス喪失・非表示・破棄に対応します。

通常の数字キーはカーソル単位、F＋数字キーは選択ノートの記譜上の音符種類を変更します。
音符種類を変えても付点は維持し、F＋ドットで付点なし／付点一つを切り替えます。
16分グリッドに収まらない付点16分、他ノートへの衝突、小節末を越える変更は拒否します。
音価変更では休符を消費・補完し、タイがある場合は選択ノートの後続タイ音符だけを動かします。
明示的な音価変更ではノートID・和音・ピッチ選択・入力単位を保持します。
F＋左右は別の便利操作として、タイ列の開始位置を固定し、合計音価を入力単位ずつ加減して再構成します。
保存するのは音符種類・付点・タイ・休符の列であり、数値の長さや開始位置をノートに追加しません。
再構成後は末尾ノートへフォーカスします。入力単位は保持し、長さ0以下や他ノートとの衝突は拒否します。
F＋右で小節末を越えた場合、既存の次小節の必要な範囲が休符なら、小節境界で分割してタイ接続します。
複数の既存小節にも伸ばせます。他ノートとの衝突・曲末超過は操作全体を拒否し、小節は自動追加しません。
F＋Aは引き続き、指定音価のノートを明示的に追加する操作として使えます。
音価は小節内の開始位置と拍子を考慮し、拍の分割位置を見せる記譜を優先します。
音符の基本単位に位置を合わせ、拍の途中から始まる音は次の拍を隠さないよう分割します。
複合拍子は付点4分のまとまりを使い、細かい音符の位置はその拍の中で判定します。
小節境界と指番号の変わる境界も残し、その条件内で単付点までの音価を使って音符数を最小化します。
同数なら付点のない先頭音符を優先するため、7ステップは4分＋付点8分となります。
4/4の16分裏から伸ばす場合、合計1〜4ステップは16分、16分＋16分、16分＋8分、16分＋8分＋16分となります。
範囲外の休符やノートは維持します。
通常の音価指定・F＋Aでは自動結合しません。F＋左右を使った範囲だけが自動整形の対象です。
F＋数字による明示指定では、16分位置から4分音符を書くなど自由な音価指定を保持できます。
F＋Aは全ピッチと指番号を複製し、新しいノートの音価に入力単位を使います。対応するピッチの選択と入力単位を保持します。
D＋Aも全ピッチと指番号を複製し、現在のノートの直後にタイ接続せず配置します。新しいノートへフォーカスします。
既に後続のタイ接続があるノートでは追加しません。列の末尾を選んで延長します。
小節末からは既存の次小節の先頭へ接続できます。他ノートとの重なり、追加音符の小節末超過、曲末超過は拒否します。
元ノートの音価を変えたり、自動で結合・分割したりせず、個々の音符とタイ関係を保存します。
ノート移動では元の音価・和音・指番号・選択状態を保ち、移動元を休符へ戻して移動先の休符を消費します。
移動先の同声部ノートとの重なり、曲の範囲外、音符単体が小節境界をまたぐ移動は拒否します。
Scorehackと同じく衝突は移動先で判定し、途中を通過する他ノートや休符は保持します。
各音符が収まる場合は既存の隣接小節へ移せます。小節の自動追加・音符の自動分割は行いません。
タイのID構造と、既存のピッチ編集・削除・アウトライン変更時の接続整合処理は保持します。

## 小節ごとのアクティブ声部

声部は小節・段のローカルな記譜要素です。全曲共通のトラックではありません。
アクティブ声部はカーソルの一時状態（voiceIndex、内部0始まり／画面1始まり）として管理します。
Shift＋Qは次のインデックスがなければ全小節休符で追加するだけで、フォーカス・選択・入力単位を変えません。
既存の次声部がある場合、第3声部からの追加、対象小節がない場合は何もしません。声部削除は未対応です。
Qで切り替えるとノート・範囲選択を解除し、ノート開始位置と選択ピッチ（範囲選択なら操作端の最高音）へカーソルを置きます。入力単位は維持します。
カーソル移動先に同じ声部があれば維持し、なければ第1声部へ戻します。第2・第3声部を編集中、その声部のない小節は黒のopacity:0.4で覆います。
段切り替えとOutlineからTimelineへ入る際も第1声部へ戻します。
タイ追加・伸長・移動などの編集は、必要な小節に同じ声部がなければ操作全体を拒否し、第1声部への振り替えや声部の自動作成はしません。
範囲選択は別インデックスの声部へ跨がせません。

## 表示

左にOutline、右に時間軸ヘッダ・88鍵ピッチ一覧・ピアノロールを配置します。
Outlineモードでは上下段の全声部を表示し、ノートを行の中央に高さ12pxで配置します。
上段は暗い青（RGB 0, 0, 100）、下段は暗い赤（RGB 100, 0, 0）を基準に、縦方向の中央が少し明るいグラデーションと透明度0.8で表示します。枠線・角丸・タイ曲線を表示しません。
横位置・表示幅・独立ノート間の4pxの隙間はTimelineと共通です。タイでつながる音は境界のない帯として見えます。
Timelineモードではアクティブ声部を高さ24px・調性による色・角丸で表示し、非編集段・非アクティブ声部をOutlineと同じ半透明表示で残します。タイ曲線・ノートフォーカス・範囲選択はアクティブ声部だけに表示します。
最低サイズはScorehackを基準とする1100×800px。レスポンシブ再配置やスクロールバー表示は行いません。
カーソルに応じて自動追従し、時間軸ヘッダとピアノロールの横位置を同期します。
スクロールは15段階・10ms間隔で補間し、キーリピート中も追従します。

カーソルは選択中の単位の配置範囲を示します。配置範囲が他ノートに重なるか小節末を越えると赤く表示します。
ノートフォーカス中はカーソルを隠し、`Note 1/4 · Input 1/16`のようにノート音価と入力単位を並べます。
Note側の文字は淡い暖色、Input側は白で区別します。入力カーソルではInputだけを表示します。
ノートの色は調性内／調性外で決まり、フォーカスは列の色で示します。
Timelineモードのアクティブ小節色はヘッダのメジャー行だけに表示します。

## 楽譜プレビュー

Timelineモードだけ、ピアノロール右上8pxに480×240pxの固定フレームを表示します。
OSMD 2.2.1へ現在小節と前後の実在する小節をMusicXMLとして渡し、SVG上の現在小節の中心をフレーム中央に合わせます。
曲頭・曲末の存在しない隣接小節は補わず空白になります。左右の小節はフレームで切り抜きます。
現在小節は薄黄色で示し、上下段と全声部の音符・休符・付点・和音・表示範囲内のタイを描画します。
描画は80msまとめて更新し、同じ小節内のカーソル移動だけでは再描画しません。古い非同期描画は破棄します。

初期検証の制限：音名は現在の調号に基づく仮の自動綴りで、ユーザー指定の異名同音表記は未対応です。
表示範囲の外へ続くタイの端は省略します。非常に密な小節や広い音域では、全体を収めるため音符が小さくなります。
MusicXMLは表示用の変換結果であり、ファイル出力やMuseScoreとの互換検証を完了したものではありません。
ブラウザのSVG描画を使うため、OSMD依存のNode向けネイティブglビルドは無効にしています。

## ファイル

- `src/model/project.ts`：プロジェクト・記譜要素の型、音価からの時間導出、全小節休符、休符の既定分割
- `src/model/score-preview.ts`：前後小節のMusicXML生成、仮の音名綴り、中央配置の計算
- `src/components/ScorePreview.svelte`：OSMDの遅延読み込み、SVG描画、固定フレーム内の切り抜き
- `src/model/pitch-collision.ts`：段・声部IDと導出した時間区間による、別声部との同音衝突判定
- `src/state/outline-cursor.ts`：アウトライン移動、要素の追加・削除
- `src/state/timeline-cursor.ts`：一時カーソル、記譜列からの位置導出、音符配置・削除、和音編集
- `src/state/key-hold.svelte.ts`：ホールド状態と解除
- `src/components/TimelinePanel.svelte`：導出位置によるピアノロール描画と自動追従
- `src/components/OutlinePanel.svelte`：アウトライン表示と自動追従
- `src/components/InitialValues.svelte`：初期値・現在位置の表示

Tauri導入、休符の表示・手動整形、声部削除、MusicXML入出力は後の段階で検討します。
