# Piano Score Editor

ソロピアノ譜の入力操作と、音価・タイの正規化を段階的に検証するアプリです。
Svelte 5 + TypeScript + Viteで構成します。
アプリの正式なUI表記は英語で統一します。検証中のレイアウト用メモ書きは日本語でも構いません。

目的、Scorehackから引き継ぐ方針、ドメインモデル、未決事項は[score-domain-model計画](../../docs/plan/score-domain-model/score-domain-model.md)を参照してください。

## 起動

Node.js 24系とpnpmを使用します。このディレクトリで実行してください。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

表示されたローカルURLをブラウザーで開きます。

```powershell
pnpm check
pnpm build
```

## 現在の実装範囲

プロジェクトデータの最小構造と、アウトラインの初期値・セクション・小節の表示およびカーソル移動。

- 画面上部：操作モードを表示する領域と、上段・声部0の表示
- 左側：現在位置の情報を表示する領域と、アウトライン
- 右側：時間軸ヘッダ、ピッチ一覧、ピアノロールの各領域

プロジェクトは順序付きの`outline`を持ち、先頭に初期値ブロック、その次に最初のセクションを置きます。
セクションの初期名はScorehackと同じ`section0`です。
セクションは区切りの要素とし、今後の小節ブロックも同じ配列に並列で置きます。
小節は直前のセクションに属するものとして扱い、セクション自身には小節の配列を持たせません。
小節は上段・下段を持ち、各段にvoice 0を用意します。ノートは小節内の16分音符単位の開始位置、分数の音価、
複数音高の配列を持ちます。現状の入力対象は上段voice 0で、各ノートは単音です。
初期値は調号（長短調を持たない`fifths`）、
拍子（Scorehackと同じ`unit`・`cnt`）、テンポです。
作成時の値は、調号なし・4/4・4分音符＝100です。
アウトラインの初期値ブロックと現在位置の情報は、同じプロジェクトデータから表示します。

`r`キーでOutlineとTimelineの編集モードを切り替えます。
Outlineモードでは、選択中のブロックIDをプロジェクトとは別の編集状態として保持します。
初期位置はScorehackと同じ最初のセクションです。上下矢印キーで前後の要素へ移動し、
左右矢印キーでセクション間を移動します。選択中のブロックは薄い色の重ね表示で示し、
アウトラインとタイムラインはフォーカス位置へ自動追従します。

Timelineモードのカーソルもプロジェクトとは別に、全体位置（16分音符単位）とMIDI音高を保持します。
左右矢印キーで選択中の操作音価ずつ移動し、上下矢印キーで半音ずつ移動します。
ノートをフォーカスした状態の上下矢印キーは、そのノートのピッチを半音ずつ変更します。
`1`・`2`・`3`キーで操作音価をそれぞれ16分音符・8分音符・4分音符に切り替えます。
操作音価はカーソルの長さ表示として示し、ノートの音価とは分けて扱います。
`a`キーでカーソル位置に操作音価のノートを置き、置いたノートをフォーカスします。
既存ノートとの重なり、または小節内に収まらない位置では配置できず、カーソルを赤く表示します。
左右移動でノートに当たるとそのノートをフォーカスし、フォーカス中の左右移動でノートの開始／終了位置へカーソルを出します。
ノートから出る際は操作音価をそのノートの音価に合わせます。
カーソル位置に応じてアウトラインの小節フォーカスを同期し、音高欄も表示します。
どちらのモードでも、矢印キーによる移動でブラウザーのスクロールを発生させません。
タイムラインはカーソル位置に合わせて横スクロールし、ヘッダのメジャー行とピアノロールの位置を同期します。
スクロールはScorehackと同じ15段階・10ms間隔で補間し、キーリピート時は現在位置から新しい目標へ追従します。
Outlineモードの`a`キーでカーソル位置の次に小節を追加し、フォーカスはそのまま維持します。
`s`キーでカーソル位置の次にセクション（初期名`section`）を追加し、フォーカスはそのまま維持します。
初期値ブロック上で追加した場合は、最初のセクションの後に追加します。
小節の初期長は直前の小節、直前に小節がなければ初期拍子から引き継ぎます。

ScorehackのTauri設定を基準に、レイアウトの最小サイズは1100×800pxとします。
それより小さい表示領域では、レイアウトの一部が表示領域から隠れます。
アプリ内のスクロールバーは表示せず、必要な移動はキーボード操作に応じて自動追従させる方針です。
画面幅に応じたレイアウト・文字サイズの切り替えは行いません。

初期値の変更、ノートの移動・音価変更、タイによる小節またぎは今後の段階で実装します。
同じピアノロールで上下段・複数声部を扱う構造を持ちます。

## ファイル

- `src/App.svelte`：画面全体のレイアウト
- `src/model/project.ts`：プロジェクト・初期値・セクション・小節・譜表・声部・ノートの型と初期データの生成
- `src/state/outline-cursor.ts`：プロジェクトと分離したアウトラインのカーソル状態・移動・小節／セクション追加
- `src/state/timeline-cursor.ts`：プロジェクトと分離したタイムラインカーソル位置・音高・移動
- `src/components/OutlinePanel.svelte`：左側の領域
- `src/components/InitialValues.svelte`：データから調号・拍子・テンポを表示
- `src/components/TimelinePanel.svelte`：右側の領域
- `src/style.css`：共通スタイルと領域の寸法

Tauriの導入は本格的なアプリを作る段階で検討します。
